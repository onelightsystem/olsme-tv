# **App Name**: Awake Chat

## Core Features:

- Random Video Chat: Initiate a random video chat with another user. The matching algorithm is optimized for quick connections, ensuring minimal wait times.
- AI Politeness Monitor: Utilize sentiment analysis as a tool during video chats. Scores are not stored but provide feedback during the chat to guide users. 
- Biofeedback Prompts: Integrate calming audio prompts (e.g., nature sounds, guided meditations) that play during wait times and can be activated during chats to encourage mindful communication.
- User Reporting: Allow users to report inappropriate behavior. Reports are reviewed to improve AI detection algorithms and address policy violations.
- User Authentication: Enable secure user authentication to ensure each user is uniquely identified.

## Style Guidelines:

- Primary color: Warm gold (#FFD700) to evoke a sense of sunlight and awakening.
- Background color: Soft, desaturated beige (#F5F5DC) to create a calm, inviting atmosphere.
- Accent color: Muted orange (#FFA500) to highlight interactive elements and calls to action.
- Body and headline font: 'PT Sans', a humanist sans-serif, combines a modern look and a little warmth.
- Use soft, rounded icons with a hand-drawn style to promote a friendly and approachable feel. Icons should primarily be white on the background color, or the primary color on interactive elements.
- Employ a clean, minimal layout with plenty of whitespace to reduce visual clutter and promote a sense of calm.
- Use subtle, slow animations for transitions and feedback, avoiding anything jarring or distracting. For example, gently pulse the call button to draw attention without being intrusive.
